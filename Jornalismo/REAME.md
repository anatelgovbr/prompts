# Jornalismo

> Criar notícias, revisar textos jornalísticos e preparar divulgação para WhatsApp.

Sugestão de "Descrição do Prompt" para cadastro na Galeria de Prompts:

```text
Criar notícia baseada em textos de entrada e destaques informados.
>>> Adequar o prompt para quando for apenas colar textos de fonte em "texto_fonte_1" e "texto_fonte_2" ou utilizar Documento Referenciado: #xxxxxxxx (opcional).
>>> Alterar "xxxxxxxx" ao final para o protocolo do documento.
```

```text
Revisar texto jornalístico.
>>> Adequar o prompt para o caso de não informar os exemplos "exemplo_bom_de_noticia_1" e "exemplo_bom_de_noticia_2".
```

```text
Criar divulgação para WhatsApp sobre notícia publicada.
>>> Não esqueça de colar o texto completo da notícia entre as chaves "texto_noticia_publicada".
```
