# Criador de Estórias de Usuário para desenvolvimento de sistema a partir de reunião gravada pelo Teams

> Cria Estórias de Usuário para desenvolvimento seguindo boas práticas do Scrum

Sugestão de "Descrição do Prompt" para cadastro na Galeria de Prompts:

```text
Copilot (https://copilot.microsoft.com/) M365/Teams: Cria Estórias de Usuário para desenvolvimento de sistema a partir de reunião gravada pelo Teams
   :: No Copilot, cole a URL do "Assistir no navegador" da Gravação da Reunião pelo Teams na última linha do prompt.
   :: No SEI, anexe o vídeo da gravação.
   :: Quase ao final do prompt, para outros sistemas, altere as "Informações sobre o “Sistema”" e "Denominações dos Papéis de Usuário"
```
