# Otimizador de Prompts

> Criar ou revisar prompts e ideias brutas conforme o Modelo de Prompt Perfeito.

Sugestão de "Descrição do Prompt" para cadastro na Galeria de Prompts:

```text
Criador do Prompt Perfeito - Criar ou revisar um prompt a partir de um prompt existente ou de uma ideia
> Cole o prompt existente ou descreva a ideia entre as tags <prompt_original_ou_ideia> e </prompt_original_ou_ideia>.
> O resultado será estruturado no Modelo de Prompt Perfeito: Persona, Contexto, Tarefa/Objetivo, Restrições, Instruções e Formato.
> Separa bem Restrições, que definem proibições e regras rígidas, de Instruções, que definem como executar a tarefa.
```
